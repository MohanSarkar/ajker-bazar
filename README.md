# বাজার দর / BazarDor 🛒

"বাজার দর" হলো বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের সঠিক ও হালনাগাদ বাজার দর ট্র্যাক করার একটি আধুনিক এবং রেসপন্সিভ ওয়েব অ্যাপ্লিকেশন। এর মাধ্যমে ব্যবহারকারীরা খুব সহজেই চাল, ডাল, তেল, সবজি, মাছ-মাংসসহ বিভিন্ন নিত্যপণ্যের দৈনিক দামের পরিবর্তন এবং বাজারভিত্তিক তুলনামূলক মূল্য দেখতে পারেন।

---

## 🚀 Technologies Used

* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Authentication:** Better Auth (GitHub, Google OAuth, & Credentials)
* **State Management & Architecture:** React Context API & Component-Based Design

---

## ✨ Key Features

1. **Top Price Ticker (রিয়েল-টাইম প্রাইস টিক্কার):** নেভবারের নিচে ইনফিনিট স্ক্রোলিং স্ট্রিপের মাধ্যমে ট্রেন্ডিং পণ্যের দাম এবং শতকরা পরিবর্তন (▲/▼) রিয়েল-টাইমে প্রদর্শন করা।
2. **Dynamic Product Sections (পণ্যের ক্যাটাগরি ও দামের তারতম্য):** হোম পেজে "আজ দাম বেড়েছে", "আজ দাম কমেছে" এবং "সব পণ্য" সেকশনগুলো সুন্দর গ্রিড ও কার্ড লেআউটে সাজানো।
3. **Advanced Market Comparison (/product/[slug]):** নির্দিষ্ট পণ্যে ক্লিক করলে তার সর্বনিম্ন, সর্বোচ্চ, এভারেজ প্রাইস এবং বিভিন্ন বাজারেরভিত্তিক দামের বিস্তারিত তালিকা দেখার সুবিধা।
4. **Secure Authentication & Profile Management:** Better Auth ব্যবহার করে ইমেল-পাসওয়ার্ডের পাশাপাশি সোস্যাল লগইন (Google ও GitHub) এবং ইউজার সেশন ম্যানেজমেন্ট।
5. **Smart Sorting & Responsive UI:** বাংলা সংখ্যা ও ভ্যালু সঠিকভাবে হ্যান্ডেল করে সর্টিং (ডিফল্ট, কম থেকে বেশি, বেশি থেকে কম) কন্ট্রোল এবং সব ডিভাইসে (মোবাইল ও ডেস্কটপ) পারফেক্ট রেসপন্সিভ ডিজাইন।
